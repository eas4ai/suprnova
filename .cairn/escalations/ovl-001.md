DECISION

Question:   Agree OVL-001 to OVL-006 in docs/spec/component-library-overlays.md as the overlays commitment (tooltip, collapsible and accordion, popover, single-level dropdown menu, dialog, sheet, drawer: native details, popover attribute and dialog for open state before any script, browser-local open state, focus return on close, keyed morph continuity)? One thing blocks it as written: OVL-001 requires the native popover attribute, which shipped in Chrome and Edge 114, Firefox 125 and Safari 17, while Live's supported baseline (Live spec 00, the Tailwind 4 floor) is Chrome and Edge 111, Firefox 128 and Safari 16.4; on Chrome 111-113 and Safari 16.4-16.6 a popover would simply render open and inline.
Recommend:  Answer ok: agree the six as one set and raise the supported baseline to Chrome and Edge 114, Firefox 128 (unchanged) and Safari 17, recorded as a dated revision in Live spec 00 and 23, the compatibility matrix floors (chrome-minimum-114, edge-minimum-114, safari-minimum-17) and the manual; the accordion's single-open mode (details name) degrades to multi-open below Chrome 120, Firefox 130 and Safari 17.2, which the review records as a known limit rather than a new floor.
Because:    Native open state is the whole point of OVL-001 (no script owns focus containment or light dismiss, so the checker and the base-layer-stripped harness can prove the components), and the three browsers below the new floor are 2023 releases that auto-update; keeping them would force a script-toggled popover that contradicts the requirement you are agreeing.
If wrong:   Users on Chrome 111-113 or Safari 16.4-16.6 see the popover and dropdown menu permanently open; the floor change is a documented support statement, not a code change, and can be reverted by superseding the revision.
Instead:    Keep the Chrome 111 and Safari 16.4 floor and revise OVL-001 so the popover and dropdown menu toggle the hidden attribute from a vendored script, with the popover attribute only as an enhancement where present; the tooltip, accordion, dialog, sheet and drawer stay native.
