# Suprnova Live -- Iteration 007

Status: Scope contract
Agreed: 2026-09-13

## In

This contract mirrors the Cairn commitment `component-library-foundations`,
agreed 2026-09-13. Iteration 007 builds the foundations of the official component library
under the Cairn record at `docs/spec/component-library-foundations.md` and
`docs/spec/component-library-forms.md`, which refine specs 20 and 21 into
requirements with falsifiers and mechanisms. Its scope is the agreed set
UI-001 to UI-019 and FORM-001 to FORM-004:

- The token stylesheet and base layer under the `suprnova-ui` cascade layer
  with `--sn-` tokens, light and dark, delivered as the `ui-styles` runtime
  artifact a document opts into with `LiveBootstrapOptions::with_suprnova_ui`
  (spec 09, manifest schema 3), and a Tailwind CSS 4 `@theme` preset.
- The form family's presentational tier as Askama macros, one directory per
  component with a JSON manifest, installed by `live:add` under
  `templates/suprnova-ui/` and served at `/suprnova-ui/<component>/<file>`.
- The checker expanding macro calls (spec 19), so a library view passes
  `live:check` without `--allow-unproved`.
- Explicit registration under the reserved `suprnova.` namespace, light-DOM
  `sn-` custom elements defined only by their component's script, and the
  headless rule: no inline style, no literal visual value, state styled from
  the attributes the checker proves.

## Out

The behavioral and enhancement tiers of the form family (FORM-005 to
FORM-008), the navigation, overlay, feedback, and data-display families, and
the shared element helper stay with the commitments that follow.
