# Suprnova Live -- Iteration 008

Status: Scope contract
Agreed: 2026-09-14

## In

This contract mirrors the Cairn commitment `component-library-overlays`,
agreed 2026-09-14. Iteration 008 builds the overlay and disclosure family of
the official component library under the Cairn record at
`docs/spec/component-library-overlays.md`, which refines spec 23 into
requirements with falsifiers and mechanisms. Its scope is the agreed set
OVL-001 to OVL-006:

- Tooltip, collapsible and accordion, popover, single-level dropdown menu,
  dialog, sheet and drawer as Askama macros, one directory per component
  with a JSON manifest, installed by `live:add` and served beside the form
  family.
- Native open state before any script: `details`, the `popover` attribute
  and `dialog` own open state, focus containment and light dismiss; the
  tooltip is CSS only; the menu is a single-level list of anchors and
  action buttons.
- Browser-local open state: no open or close control carries a Live
  directive; a server action invoked from an overlay owns only its effect.
- Focus return to the invoker, or to the host element when the invoker left
  the document, proven on chromium, firefox and webkit.
- Keyed continuity: every overlay root carries a stable key and
  `live:preserve.self`, so its open state survives a compatible morph and an
  unkeyed root follows the server.
- The supported baseline raised to Chrome and Edge 114 and Safari 17 for the
  `popover` attribute (spec 00, 2026-09-14).

## Out

Nested submenus (a separate project by the 2026-09-13 ruling), the layer and
teleport management of spec 23, hover cards, context menus, and the
feedback, navigation and data-display families stay with the commitments
that follow.

## Implementation checkpoints

1. The spike: native primitives, anchor positioning and keyed continuity on
   the three engines, recorded in the review.
2. The eight component directories and the dogfood overlay gallery.
3. The mechanisms, the browser cases and the morph continuity fixtures.
4. The manual section, the changelog entry and the six mirrors.

## Definition of done

Every mechanism the commitment names passes on a committed tree and the
review at `.cairn/reviews/component-library-overlays.md` is recorded.
