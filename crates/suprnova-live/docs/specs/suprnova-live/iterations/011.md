# Suprnova Live -- Iteration 011

Status: Scope contract
Agreed: 2026-09-15

## In

This contract mirrors the Cairn commitment `component-library-live-native`,
agreed through escalation `form-005` under the developer's 2026-09-14 ruling
that every remaining roadmap commitment is agreed. Iteration 011 builds the
live-native family of the official component library, the last item on the
roadmap, under `docs/spec/component-library-forms.md` (FORM-005 to
FORM-008), `component-library-feedback.md` (FDB-005) and
`component-library-navigation.md` (NAV-005):

- The upload widget over the shipped upload protocol: the file input
  carries the island's upload field, the progress element is the runtime's
  progress root, every state is rendered text, and nothing reads as saved
  before the finalizing action.
- The live feed and the notification bell on a stream-backed island,
  carrying the runtime's stream status announcements so a degraded,
  reconnecting or closed stream says so.
- The account menu as a details disclosure with anchors and a
  CSRF-protected sign-out form, documented as a stitch slot and mounted as
  the dogfood dashboard's fourth slot.
- The custom-element tier: input OTP, date picker and combobox as light-DOM
  `sn-` elements defined by their own vendored files, holding no form value,
  over native controls that submit the same value with the script blocked;
  the combobox refuses a listbox rendered for an older query.

## Out

No JavaScript helper library as the element base (escalation `form-005`);
tag and token input and the multi-value combobox; the complex blocks the
roadmap excludes (auth flows, command palette, drag-reorder, carousel, rich
text editor and the rest).

## Implementation checkpoints

1. The seven component directories (upload, live-feed, notification-bell,
   account-menu, input-otp, date-picker, combobox), the dogfood live-native
   page with its two islands, the sign-out route and the dashboard's fourth
   slot.
2. The mechanisms, one owner per requirement: the live-native tool
   (FORM-006, FORM-007), the combobox fixture (FORM-008), the feed status
   fixture (FDB-005) and the dogfood tests (FORM-005, NAV-005), with the
   inherited runs over the new directories.
3. The Playwright case per engine that upgrades every element, then blocks
   every element script and proves the native controls still submit.
4. The manual section, the changelog entry, the spec revisions and this
   contract.
5. The morph keeps the runtime's projected stream status (the root state and
   the announced text) across an action's re-render that keeps the stream,
   and hands it back to the server's baseline when the stream is dropped or
   changed, with the fixture cases and the browser assertion that prove it.

## Definition of done

Every Cairn mechanism named by the commitment passes on a committed tree,
the review is recorded and `cairn wake` reports the commitment Done.
