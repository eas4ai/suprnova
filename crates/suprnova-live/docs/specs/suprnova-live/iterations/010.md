# Suprnova Live -- Iteration 010

Status: Scope contract
Agreed: 2026-09-15

## In

This contract mirrors the Cairn commitment `component-library-data-display`,
agreed through escalation `data-001` under the developer's 2026-09-14 ruling
that every remaining roadmap commitment is agreed. Iteration 010 builds the
data display and layout family of the official component library under
`docs/spec/component-library-data-display.md`, which refines spec 25 into
requirements with falsifiers and mechanisms. Its scope is DATA-001 to
DATA-005:

- Separator, scroll area, aspect image, card, badge, avatar and avatar
  group, list group, description list and stat card, as Askama macros, one
  directory per component with a JSON manifest, installed by `live:add`.
- The chart, drawn on the server through `charts-rs` from bounded typed
  series by a library function that returns trusted SVG, with a text summary
  and a data table beside the marks and no client charting runtime.
- The datatable, the last component the library builds: a native table, one
  island per table, whose sort, direction, filter and page are `#[url]`
  fields reflected into a shareable URL after every action and mounted from
  the document's query.
- Layout primitives that keep document order and label every region and
  group; status components that carry text for every variant; collections
  whose items carry stable keys through `live_key`.

## Out

The interactive data grid stays an opt-in pattern outside the built-in set;
no client-side chart, by the 2026-09-13 ruling; the code block, prose and
media containers are not named by the roadmap; the live-native family
follows in its own commitment.

## Implementation checkpoints

1. The eleven component directories, the charts module and the dogfood
   data-display page with its two islands.
2. The mechanisms: the data-display tool, the collection morph fixture, the
   dogfood document tests, the live:check run and the browser cases.
3. The manual section, the changelog entry and the six mirrors.

## Definition of done

Every mechanism the commitment names passes on a committed tree and the
review at `.cairn/reviews/component-library-data-display.md` is recorded.
