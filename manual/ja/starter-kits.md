# スターターキット

スターターキットは、フォークしてデプロイできる事前に構築された Suprnova アプリケーションです。各キットは完全な製品サーフェス用にコントローラー、ルート、マイグレーション、フロントエンドページ、テストを設定しています。そのため、空のスキャフォルドではなく、実行中のアプリから開始できます。

現在、Laravel の流れに基づいてモデル化された 3 つのキットが提供されています。構築中のものに最も近いものを選んで、そこからカスタマイズしてください。

## Nebula - 認証 （Breeze レベル）

**リポジトリ: [github.com/eas4ai/Nebula](https://github.com/eas4ai/Nebula)**

最小限の完全認証キット - Suprnova の Breeze に相当します。アカウントに必要なすべてのものがあり、不要なものはありません：

- メール検証付きの登録
- リメンバーミー付きのログイン
- 列挙防止レスポンス付きのパスワードリセット
- プロフィール管理 - メールとパスワードを更新、アカウントを削除
- ブランド化された Inertia 3 + Svelte 5 フロントエンド （デフォルトはダーク）、ログイン済みユーザーメニューが設定されている

Nebula は 2 つのテストスイートを提供しています。ファサードレベルの認証ロジック、および実際のルート、セッション、CSRF ラウンドトリップ、ゲスト / 認証 / 検証ゲートをループバックソケット経由で駆動するHTTP 通信レベルのスイートの 2 つです。

自分の製品を構築するためのシンプルなアカウント管理の基盤が欲しいときは Nebula を選んでください。

## Pulsar - 製品サイト＆コミュニティ

**リポジトリ: [github.com/eas4ai/Pulsar](https://github.com/eas4ai/Pulsar)**

Vue 3.5 + Vuetify で構築された開発者向けツール / SaaS カンパニー向けの完全なサイト。Nebula の認証ストーリーのすべてに加えて、実際の製品サイトが必要とするサーフェスを備えています：

- マーケティング ランディングページとユーザーダッシュボード
- 検索と自動生成された目次付きの Markdown ドキュメントパイプライン (`docs:build`)
- RSS フィード付きのブログ / 記事システム
- 公開メンバープロフィール
- タクソノミー - トピック、タグ、カテゴリー
- ロールベースアクセス制御：ロール、権限、ゲート
- コンテンツとメンバーの管理および調整サーフェス

Pulsar は `suprnova.app` などの下流製品向けのソースキットです。ドキュメント、ブログ、メンバーコミュニティを備えた製品サイトをデプロイするときに選んでください。認証機能だけが必要な場合ではありません。

## Directory starter - リスティング、モデレーション、有料公開

**リポジトリ: [github.com/eas4ai/suprnova-directory-starter](https://github.com/eas4ai/suprnova-directory-starter)**

Vue 3.5 で構築された、MIT ライセンスの無料ディレクトリ。オーナーがリスティングを投稿し、モデレーターが審査し、訪問者が検索し、公開は無料、または Stripe と Paddle による有料です。Nebula の認証ストーリーのすべてに加えて：

- ディレクトリの探索 - 検索可能なリスティング、カテゴリーフィルター、ページネーション、公開の詳細ページ
- オーナーの投稿とモデレーション - 下書き、改訂履歴、承認、却下、再投稿、停止
- 無料および有料の公開 - Stripe と Paddle、設定可能なプラン、テストと本番の個別設定、認証付きウェブフック、決済のリカバリー
- 編集公開 - 記事の下書き、プレビュー、カテゴリー、タグ、RSS
- 管理 - 権限ベースのロール、アカウントの停止、監査履歴、管理者向けの概要
- SEO - サイト既定値とコンテンツごとの上書き、サーバーでレンダリングされるメタデータ、サイトマップ、リダイレクト、404 レポート、公開ページの Markdown 版
- メディアと通知、ライト / ダークの設定を記憶するカラープリセット、デモコンテンツ、文書化されたバックアップとリストアの手順

製品がリスティングのディレクトリやマーケットプレイスであるとき（有料掲載の有無を問わず）は、directory starter を選んでください。

## どのキットを選ぶか

| あなたが欲しいもの | 選択すべきもの |
|---|---|
| アカウントと構築する場所 | **Nebula** |
| 完全な製品サイト - ランディング、ドキュメント、ブログ、コミュニティ、RBAC | **Pulsar** |
| リスティングのディレクトリまたはマーケットプレイス（無料または有料） | **Directory starter** |
| API のみのバックエンド （トークン認証、フロントエンドなし） | `suprnova new my-api --api` |

3 つのキットはいずれもフレームワークを git 依存性として追跡し、既に知っているのと同じスタック上で実行されます。セットアップについては各リポジトリの README を参照してください。さらに多くのキットが予定されています。[リリース](https://github.com/eas4ai/suprnova/releases)を確認するか、欲しいものがあればイシューを開いてください。

## デフォルトスキャフォルドが提供するもの

どちらのキットにも適さない場合、`suprnova new my-app --frontend svelte` （または `react`、`vue`） は、既に動作している認証フロー - ログイン、登録、ログアウト、メール検証、パスワードリセット、`authenticate` ミドルウェア付きセッション認証、CSRF 保護、保護された `/dashboard` ルート - を 3 つのフロントエンド (Svelte 5、React 19、Vue 3.5) のいずれかで提供しており、Tailwind v4 および Inertia v3 が付属しています。スキャフォルド出力については[インストール](installation.md)を、最初の 5 分間のウォークスルーについては[クイックスタート](quickstart.md)を参照してください。

APIのみのサービスでは、`suprnova new my-api --api` がMagnetarを初期化し、bearerセッションミドルウェアを導入して、フロントエンドなしに正規の `app_users` テーブルに対するパスワード登録とログインをスキャフォルドします。
