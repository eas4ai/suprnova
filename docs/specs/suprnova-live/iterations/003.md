Status: Scope contract

## In

Iteration 003 is the complete standalone browser interaction runtime. It turns
the iteration-001 protocol spine and iteration-002 server-component kernel into
an end-to-end browser experience for server-rendered Live islands: deterministic
runtime delivery, island discovery, closed directives, browser-local signals,
optional Stimulus controllers, per-island scheduling, truthful feedback,
server-action transport, commit-after-morph response application, keyed DOM
continuity, and enhanced real-document navigation.

The implementation remains inside this dedicated development workspace and
continues to target the eventual internal Suprnova crate. Production artifacts,
host-neutral asset metadata, fixtures, and a browser test host prove the runtime
contract without claiming that the active Suprnova checkout serves or registers
the assets. No source or path dependency on Suprnova or Magnetar is introduced.

### Runtime artifacts, configuration, and bootstrap

- [`09-runtime-bootstrap-and-directives.md`](../09-runtime-bootstrap-and-directives.md)
  -> turn `browser/` from a conformance-only package into the strict-TypeScript
  production runtime while retaining the existing canonical, protocol,
  compatibility, and response-ordering modules as validated boundaries.
- Build deterministic, versioned ESM and classic-script artifacts that contain
  the same core behavior and the pinned Idiomorph implementation. Applications
  shall not need Node, npm, a bundler, Stimulus, or a client framework merely to
  use the shipped assets. Source maps remain development artifacts by default.
- Emit a host-neutral typed asset manifest with content hashes, runtime and
  protocol compatibility, content type, preload/module intent, and production
  cache metadata. A standalone test server may serve the manifest and artifacts;
  no Suprnova asset route or public facade is claimed.
- Parse bounded server-emitted configuration for endpoint, runtime/protocol
  versions, timeouts, concurrency, diagnostics, asset identity, and non-secret
  feature flags. Endpoint targets must be safe same-origin or explicitly
  host-approved URLs and cannot come from an element-level directive.
- Bootstrap exactly once per active document. Duplicate artifact loading,
  module/classic coexistence, pageshow restoration, and extension registration
  cannot duplicate the core observer, delegated listeners, island records, or
  diagnostics.
- Support external module/classic scripts plus nonce and hash-based CSP. A
  missing, blocked, failed, or incompatible runtime leaves initial HTML exposed,
  keeps Live-dependent behavior disconnected, and reports only bounded redacted
  application-developer diagnostics.

### Island discovery, ownership, directives, and delegated events

- Discover server-rendered island roots in deterministic document order and
  validate their root shape, component and slot identity, protocol/runtime
  compatibility, endpoint association, seed-or-instanced snapshot form, and
  document-local uniqueness before connection.
- Create one document-local island record and bounded scheduler per connected
  island. Seed-backed discovery creates no server state or eager request; a
  cryptographically random at-least-128-bit proposed nonce is created only while
  building the first server intent, is retained for that intent's permitted
  retries until promotion resolves, and grants no authority. Failure of the Web
  Crypto source fails closed; it never falls back to predictable randomness.
- Observe bounded dynamic insertion/removal through one core document observer.
  A nested island remains an opaque independently owned boundary, and removing
  or replacing an island retires its scheduler, timers, observers, controllers,
  signals, and future response application exactly once.
- Queue a checked server-declared lazy-completion activation as one protocol-v2
  `lazy_complete` operation through the owning scheduler. Stable surviving
  identity suppresses duplicate activation across discovery and morph; removal,
  replacement, or cancellation retires pending completion normally.
- Implement one generated or shared-fixture-backed closed `live:` grammar for
  directive name, target, value, arguments, and modifiers. The Rust checker and
  browser parser must agree on every iteration-003 directive and production
  behavior for unknown, conflicting, malformed, or dynamically unproved input.
- Use delegated event handling where platform semantics permit. Resolution uses
  the composed path, nearest owning island, nested-boundary exclusion, disabled
  state, trusted-event policy, listener phase, native behavior, and explicit
  prevent/stop/once/self/key/timing modifiers without arbitrary expressions or
  executable strings.
- Bound every value derived from the DOM before it reaches local state,
  scheduling, transport, diagnostics, controller lookup, or effect dispatch.

### Local signals, presentation, Stimulus, effects, and projection

- [`10-local-reactivity-and-javascript-interop.md`](../10-local-reactivity-and-javascript-interop.md)
  -> implement typed island- or keyed-local-root signals with literal initial
  values, deterministic scope/shadowing rules, dependency tracking, batching,
  and exact disposal. Local state cannot cross islands or become snapshot,
  authorization, identity, cache, or durable domain state.
- Implement closed presentation directives for show/hide, toggle, class,
  attribute, selected/expanded state, inertness, and focus. Allowlisted names,
  safe literals, semantic HTML, `aria-*`, focusability, reduced motion, and
  initial SSR consistency are enforced without an expression evaluator.
- Preserve compatible signal values only while the same keyed ownership scope
  survives a successful morph. Removal, rekey, forced replacement, explicit
  reset, or document replacement disposes the old scope; morph failure never
  transfers signals into unrelated identity. Persistent browser storage is not
  introduced by this iteration.
- Add an optional bridge for an application-supplied Stimulus 3.2 `Application`.
  Neither Stimulus nor Suprnova's bridge/continuity implementation is imported
  into or bundled with the core runtime. The bridge is delivered as matching
  deterministic ESM/classic adapter artifacts, registers before unchanged
  `boot({ stimulus })` startup, and preserves bundler and no-bundler behavior.
  Preserved, inserted, and removed controller roots receive defined continuity,
  connect/disconnect, and failure behavior through public hooks rather than a
  patch to private morph state.
- Add duplicate-checked registries for typed browser effects and public runtime
  calls. Effect payloads use registered schemas; unknown or failing effects are
  observable and cannot execute code strings, arbitrary modules, or mutate
  snapshot/revision authority.
- Support explicit reversible optimistic local projection tied to a scheduler
  intent and rollback policy. It exposes pending rather than authoritative
  success, reconciles to accepted server HTML, and rolls back or refreshes on
  rejection, timeout, cancellation, or incompatibility.

### Per-island scheduling, models, transport, and feedback

- [`11-interaction-scheduling-and-feedback.md`](../11-interaction-scheduling-and-feedback.md)
  -> implement one bounded scheduler per island with FIFO intent order as the
  default. Queue, replace/cancel-pending, drop-duplicate, latest-only, and
  explicitly safe parallel policies declare whether they affect unsent work,
  in-flight transport, or response application.
- Implement model synchronization timing for immediate, change, blur,
  debounce, throttle, action, and submit behavior using injectable clocks.
  Timers are scoped to field/directive/island, superseded unsent proposals are
  removed, and submit incorporates the newest permitted control state exactly
  once without a later stale timer request.
- Track browser proposal, last accepted server value, dirty state, validation
  state, and in-flight ownership separately. An older update response cannot
  overwrite a newer unsent local edit; file inputs never enter ordinary JSON
  model handling.
- Build existing protocol-v1/v2 request envelopes with bounded operations,
  proposals, encoded seed or instanced snapshot, proposed promotion nonce where
  required, stable idempotency identity, correlation, and semantic extension
  rules. Transport uses configured credential, origin, media, timeout, and
  abort policy without treating browser correlation as authority.
- Expose scoped idle, dirty, queued, loading, validating, success, interrupted,
  offline, retrying, and error feedback through declarative targets. Disabled,
  busy, keyboard, delay/minimum-duration, reset, and live-region rules remain
  truthful and avoid flicker or duplicate announcements.
- Preserve the last accepted DOM and snapshot during interruption. Automatic
  retry uses the same idempotency identity, bounded exponential backoff and
  jitter, and only a contractually safe request. Navigation, removal, or local
  cancellation stops future browser application without claiming server-side
  rollback.

### Response eligibility and application state machine

- Validate media, size, JSON shape, protocol version, response kind,
  correlation, island ownership, base/successor revision, snapshot form,
  recovery intent, render root, child envelopes, URL intent, emissions, and
  extensions before uncertain output is applied.
- Redirect and protocol-v2 `navigated` URL intent are terminal: after validation
  they perform normal browser navigation without morphing, committing a
  snapshot, scheduling child delivery, dispatching response events/effects, or
  reporting an in-page success first.
- A non-redirect response follows the shared protocol order exactly: validate
  and preflight; morph or validate no-render; commit browser snapshot/revision;
  reconcile model and validation state plus focus; queue signed child deliveries
  and apply same-route URL reflection; dispatch events; invoke effects; settle
  feedback. Child requests use their own schedulers and are not atomic with the
  accepted parent morph.
- Canceled, superseded, duplicate, stale, out-of-order, incompatible, and
  navigation-retired responses have distinct bounded dispositions. A response
  may advance accepted server state without overwriting a newer browser edit.
- Morph or application-order failure after server acceptance keeps the previous
  browser snapshot and initiates a bounded `fresh_render` recovery through the
  same scheduler. The original action is never retried. Repeated recovery
  failure disconnects only the affected island and stops loops.
- Protocol, extension, controller, and effect diagnostics use stable closed
  codes and omit snapshots, signatures, cookies, tokens, transient or model
  values, private HTML, arbitrary URLs, and high-cardinality raw identity.

### DOM reconciliation, identity, continuity, and transitions

- [`12-dom-morphing-and-identity.md`](../12-dom-morphing-and-identity.md) ->
  vendor and pin Idiomorph 0.7.4 behind a Suprnova-owned adapter. Live owns
  matching-root preflight, key semantics, prohibited structures, nested-island
  opacity, lifecycle, continuity capture/restore, commit ordering, transitions,
  and recovery; no Idiomorph private API becomes public contract.
- Reconcile exactly one validated current island root with one accepted matching
  replacement root. Reject cross-island/document mutation and incidental script
  execution. Limits cover input bytes, nodes, depth, attributes, keys,
  preservation records, hooks, duration, and diagnostic retention.
- Implement stable key syntax, scope, and uniqueness. Keyed reorder moves
  logical identity; changing a key creates new identity; duplicate or ambiguous
  identity fails checker or preflight instead of guessing. Nested islands are
  opaque keyed component boundaries.
- Preserve compatible focus/focus-visible state, text selection/range, IME
  composition, scoped scroll, text/check/radio/select/multi-select proposals,
  and file-input ownership while applying deliberate authoritative server
  changes. Removed focus uses an application-declared target or safe semantic
  fallback.
- Implement distinct preserve, ignore, replace, persist, and teleport controls
  with checked ownership, stable keys, lifecycle cleanup, target uniqueness,
  focus and accessibility relationships, and no ability for third-party DOM to
  manufacture Live authority.
- Coordinate surviving local-signal and Stimulus roots through before/after
  morph hooks. Added and removed identity connects or disposes exactly once;
  hook failures cannot veto security/order validation or apply stale HTML.
- Support deterministic enter, leave, move, and state-change transition
  metadata with cancellation, timeout, reduced-motion, unsupported-platform,
  and final-state rules. Motion can never postpone authority indefinitely or
  leave false feedback state.

### Real-document navigation and browser lifecycle

- [`13-document-navigation-and-transitions.md`](../13-document-navigation-and-transitions.md)
  -> preserve native anchors, GET/POST forms, redirects, refresh, fragments,
  downloads, external links, new-tab behavior, headers, cookies, middleware,
  content negotiation, and error documents. Live never installs a client router
  or partial-document protocol.
- Apply same-route query URL reflection only with `history.replaceState` after
  the owning accepted outcome. It creates no history entry, no `popstate` Live
  action, and no alternate Back/Forward state machine; history-significant state
  performs ordinary navigation.
- Implement bounded, privacy-aware eligibility and emission for native
  `<link rel="prefetch">`, Speculation Rules, or equivalent navigation-cache
  primitives. Only explicit safe GET/HEAD targets qualify; credentials,
  principal/tenant/locale variance, server cache policy, data saver, flash
  consumption, redirects, concurrency, and cancellation are honored. Runtime
  code never injects a fetched document body.
- Feature-detect cross-document View Transitions and stable transition names.
  Reduced motion, cross-origin targets, downloads, errors, unsupported browsers,
  capture failure, timeout, or cancellation fall back to ordinary navigation
  without semantic loss.
- Preserve native history and fragment behavior while applying explicit focus
  and scroll enhancement. Dirty state and active work may opt into accessible
  leave/stay warnings but cannot trap navigation or claim already committed
  server effects were rolled back.
- Cover pagehide, freeze, resume, pageshow, unload limitations, and bfcache.
  True document replacement resets document-scoped signals and retires queues;
  restoration validates compatibility, discards late response application, and
  reconnects without duplicate listeners, observers, controllers, or resources.

## Definition of done

Iteration 003 is done only when all of the following are true:

1. The strict-TypeScript production package builds reproducible versioned ESM
   and classic-script artifacts plus one typed asset manifest from exact
   lockfiles. The artifacts expose the same runtime/protocol contract, include
   the pinned morph implementation, omit production source maps by default, and
   require no application JavaScript build tool.
2. Startup configuration is typed, bounded, redacted, and source-attributed.
   Unsafe endpoints, secrets, untrusted debug enablement, incompatible versions,
   duplicate startup, failed assets, and module/classic double loading fail
   without altering initial SSR content or duplicating runtime resources.
3. One core observer and bounded delegated listener set discovers, validates,
   connects, and retires islands deterministically. Root, component, slot,
   protocol, snapshot-form, and document-local identity errors disconnect only
   the affected region with stable diagnostics.
4. Public seed discovery performs no request and creates no ledger authority.
   Its first server intent contains a fresh untrusted random nonce of at least
   128 bits retained only for that intent's permitted retries; local interactions
   before promotion remain available; repeated activation enters one ordinary
   scheduler without duplicate promotion intent. Missing Web Crypto fails closed
   without predictable fallback.
5. Nested islands remain opaque to their parent and independently scheduled.
   Dynamic insertion uses the same validation path; removal or replacement
   retires pending application, timers, observers, signals, effects, controllers,
   and extension resources exactly once. Checked lazy-completion activation
   queues one protocol-v2 operation per surviving identity through the ordinary
   scheduler and suppresses discovery/morph duplicates.
6. The Rust checker, generated/shared grammar metadata, and runtime parser agree
   on every in-scope directive, modifier, value kind, target, conflict, and
   production fallback. Unknown or malformed markup never becomes executable or
   causes an attacker-selected endpoint, action, controller, effect, class, or
   attribute lookup.
7. Delegated event fixtures prove composed-path ownership, nested boundaries,
   disabled controls, native behavior, prevent/stop/once/self, trusted-event and
   key filters, timing, shadow boundaries, keyboard activation, repeated
